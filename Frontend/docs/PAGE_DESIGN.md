# LeafAI 页面设计规范

## 整体布局

采用「左侧固定导航栏 + 右侧主内容区 + 底部悬浮输入栏」经典三段式布局，浅色简约风格。

```
+------------------+------------------------------------+
|                  |                                    |
|   左侧导航侧边栏  |          右侧主内容区              |
|   (固定宽度)     |         (自适应宽度)                |
|                  |                                    |
|                  |                                    |
|                  |                                    |
|                  |                                    |
|                  +------------------------------------+
|                  |         底部悬浮输入栏              |
+------------------+------------------------------------+
```

---

## 一、左侧导航侧边栏

位于页面最左侧，固定宽度 **260px**，白色背景，垂直排布，不随页面滚动。

### 1. 顶部导航区

```
+----------------------------+
|  [LeafAI]            🔍   |   ← 标题 + 搜索图标
+----------------------------+
|  💬  新对话                |
|  🖥️  AI 工作台             |
|  🔗  技能·连接器·伙伴       |
|  ⚡  API 服务          →   |   ← 右侧带跳转箭头
|  ⋯  更多               ▼   |   ← 右侧带展开箭头
+----------------------------+
```

| 菜单项 | 图标 | 说明 |
|--------|------|------|
| 新对话 | 💬 | 创建新的对话会话 |
| AI 工作台 | 🖥️ | 进入 AI 工作台总览 |
| 技能·连接器·伙伴 | 🔗 | 管理与外部系统的集成 |
| API 服务 | ⚡ | API 管理页面（右侧箭头 `→` 跳转） |
| 更多 | ⋯ | 展开更多功能（右侧箭头 `▼` 展开） |

### 2. 资产分区

```
+----------------------------+
|  资产                      |   ← 分区标题
|  📄  最新一条资产记录       |   ← 仅展示最新一条
+----------------------------+
```

- 分区标题「资产」，灰色小字
- 下方仅展示最新一条资产记录，点击可进入详情

### 3. 最近生成列表

```
+----------------------------+
|  最近                      |   ← 分区标题
|  🟢  生成一份产品需求文档    |
|  🔵  分析用户反馈数据       |
|  🟠  翻译技术文档为英文     |
|  🟣  生成周报摘要          |
+----------------------------+
```

- 分区标题「最近」，灰色小字
- 列表按时间**倒序**排列，最新在上
- 每条记录：左侧**彩色圆形图标** + 右侧生成提示词摘要
- 支持滚动查看更多历史记录

### 4. 底部入口

```
+----------------------------+
|  👤  我的                  |   ← 固定在侧边栏底部
+----------------------------+
```

- 用户头像图标 +「我的」文字
- 点击进入个人中心/设置

## 二、右侧主内容区

占据页面剩余全部宽度，白色背景，从上到下分为顶部栏、文档正文、悬浮按钮三部分。

### 1. 顶部标题栏

```
+----------------------------------------------------------+
|  📄 🔲                          ⋯                       |
|                                                            |
|              文档大标题（居中）                              |
|          AI 生成可能有误，注意核实（灰色小字）               |
+----------------------------------------------------------+
```

| 位置 | 元素 | 说明 |
|------|------|------|
| 标题栏左侧 | 📄 功能图标 | 文档操作相关功能 |
| 标题栏左侧 | 🔲 页面视图图标 | 点击后**隐藏/展开**左侧导航栏 |
| 标题栏右侧 | ⋯ 更多图标 | 三个点，展开更多操作菜单 |
| 居中 | 文档大标题 | 当前文档的主标题 |
| 居中（标题下方） | 灰色提示文字 | 「AI 生成可能有误，注意核实」 |

### 2. 内容区悬浮按钮

```
+----------------------------------------------------------+
|                                                    ⬇️    |
|                                                  (箭头)  |
+----------------------------------------------------------+
```

- 位于文档正文**右下角**
- 向下箭头图标，点击后**快速滚动到下一部分内容**
- 半透明背景，悬浮于内容之上

---

## 三、底部输入栏

悬浮固定在页面底部、主内容区下方，不随文档内容滚动。

```
+----------------------------------------------------------+
|  ┌───────────────────────────────────┐                   |
|  │  发消息...                        │      AUTO       ↗️|
|  └───────────────────────────────────┘                   |
|   💬 对话  🖼️ 图片生成  🎬 视频生成  🌐 翻译  ⋯ 更多   |
+----------------------------------------------------------+
```

### 输入框区域

| 元素 | 说明 |
|------|------|
| 输入框 | 圆角白色背景，带阴影效果 |
| 占位文字 | 「发消息或按空格键说话...」 |
| 模型标识 | 右侧显示「AUTO」模型名称 |
| 发送按钮 | 上箭头圆形按钮 `↗️`，点击发送消息 |

### 底部工具栏

| 模式 | 图标 | 说明 |
|------|------|------|
| 对话 | 💬 | 默认文本对话模式 |
| 图片生成 | 🖼️ | 切换到图片生成模式 |
| 视频生成 | 🎬 | 切换到视频生成模式 |
| 翻译 | 🌐 | 切换到翻译模式 |
| 更多 | ⋯ | 展开更多功能选项 |

---

## 整体布局特点

1. **左侧固定导航**：侧边栏固定宽度 260px，不随页面滚动，负责导航与历史记录
2. **右侧自适应内容**：主内容区自适应剩余宽度，负责文档展示
3. **底部常驻输入**：输入栏悬浮固定，不随文档内容滚动，保证随时可交互
4. **扁平化浅色设计**：信息层级清晰，符合 B 端 AI 生产力工具的设计规范
5. **响应式隐藏**：通过顶部视图切换图标可隐藏/展开左侧导航栏

## 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#FFFFFF` | 侧边栏、内容区背景 |
| 页面背景 | `#F5F5F7` | 整体页面底色 |
| 主文字 | `#1A1A1A` | 标题、正文 |
| 次要文字 | `#9CA3AF` | 提示文字、分区标题 |
| 输入框阴影 | `rgba(0,0,0,0.08)` | 底部输入栏阴影 |
| 侧边栏 hover | `#F3F4F6` | 菜单项悬停背景 |
| 激活态 | `#2563EB` | 当前选中菜单高亮 |
| 彩色图标 | 多色 | 最近列表的彩色圆形图标 |

## 组件树

```
App.vue
├── Sidebar.vue                 # 左侧导航侧边栏
│   ├── SidebarHeader.vue       # 标题 + 搜索
│   ├── SidebarNav.vue          # 一级功能菜单
│   ├── SidebarAssets.vue       # 资产分区
│   ├── SidebarRecent.vue       # 最近生成列表
│   └── SidebarFooter.vue       # 底部「我的」入口
├── MainContent.vue             # 右侧主内容区
│   ├── ContentHeader.vue       # 顶部标题栏
│   ├── ContentBody.vue         # 文档正文
│   └── ScrollButton.vue        # 悬浮滚动按钮
└── InputBar.vue                # 底部输入栏
    └── InputToolbar.vue        # 输入工具栏
```
